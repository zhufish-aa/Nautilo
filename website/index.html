团队工作流 · 开发版预览

先审计划，再开工。

在会话里用 @ 引用已保存的流程。主 Agent 拟定分工，你可以改每个节点的 Harness 和模型，也可以退回整份计划。

  1. 画布编排定义节点提示词、分支与并行任务。
  2. 会话审批开始前核对分工和模型。
  3. 跟踪执行在侧栏看进度，结果回到主会话。

常见问题

我需要另外准备 API 密钥吗？

可以使用受支持的 CLI 上已有的登录账号或配置。想使用单独的 API 连接时，在「供应商与账号」里配置即可。

代码和命令在哪里执行？

桌面端管理本地项目，CLI 工具和命令在你的电脑上执行。模型请求由会话选用的供应商处理。

官网的工作流预览能体验什么？

预览用一个示例任务演示派发、并行执行、复核和交回主会话的过程。下载区对应当前公开版本。
