01编排 — ORCHESTRATIONORCHESTRATION

你下目标，
它来分工。 You set the goal.
It does the split.

主 Agent 读得懂一个模糊的目标。它决定自己做、委派给谁做，或者画出一张带依赖关系的任务图，交给不同的成员并行执行。 The main agent understands a vague goal. It decides what to do itself, whom to delegate to, or draws a dependency-aware task graph for members to execute in parallel.

每个成员在独立的 worktree 里干活：结果回传、失败重试、中断可续，全过程留痕，随时可以审计。 Each member works in its own worktree: results handed back, failures retried, interruptions resumable — every step persisted and auditable.

02能力索引 — CAPABILITIESCAPABILITIES
02.1

边界

Boundaries

每个成员有自己的角色、能力清单和禁区。命令有策略、环境变量有白名单、路径有 allowedPaths；危险操作停在审批台前，等你点头。 Every member has a role, a capability list and hard limits. Command policies, env allowlists, allowedPaths; dangerous operations wait at the approval gate for your nod.

02.2

隔离与验证

Isolation & proof

任务在 Git worktree 里隔离执行，文件级、提交级 Diff 一目了然；验证命令跑过，才进合并队列——合并按钮在你手里。 Tasks run isolated in Git worktrees with file- and commit-level diffs; only after verification commands pass do changes enter the merge queue — the merge button stays with you.

02.3

凭证与数据

Vault & locality

SQLite 存会话，凭证加密落盘，日志脱敏，诊断可导出。没有遥测，没有上传——代码和密钥自始至终只在你的硬盘上。 Sessions in SQLite, credentials encrypted at rest, logs redacted, diagnostics exportable. No telemetry, no uploads — code and keys never leave your disk.

02.4

会话工作台

Session workbench

流式消息、思考过程、工具调用、文件变更、用量统计，全部在一个界面里呈现；会话可恢复，断线可重放。 Streaming messages, thinking traces, tool calls, file changes and usage in one interface; sessions resumable, events replayable.

02.5

新手引导

Onboarding

游戏式的分步引导：检测 CLI → 创建实例 → 组建团队 → 接入项目。中英双语界面，随时可从设置重播。 A game-style guided tour: detect CLIs → create an instance → build a team → attach a project. Bilingual UI, replayable from settings.

04插件 — PLUGINSPLUGINS

一个接口，
接入所有 CLI。 One interface.
Every CLI.

实现 Adapter 接口、写一份 manifest，任何 Agent CLI 都能接入统一的会话界面。Descriptor 自动驱动检测页、实例编辑器和权限选择器——不用碰一行前端代码。 Implement the Adapter interface and one manifest, and any agent CLI joins the unified session UI. The descriptor drives detection, the instance editor and permission pickers — no frontend code required.

插件市场的 registry 就托管在 GitHub 上；上架 = 提一个 PR。OpenCode 和 Trae 是两个完整的参考实现。 The marketplace registry lives on GitHub; publishing is a pull request. OpenCode and Trae are two complete reference implementations.
