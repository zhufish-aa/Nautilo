# Nautilo Android

Android 客户端目前从开发分支的源码构建。当前公开的桌面 Release 没有 Android APK。

[Android 构建说明](https://github.com/zhufish-aa/Nautilo/blob/feat/unified-workspace-polish-20261103/apps/mobile/README.md)

安装 APK 后，在支持远程连接的 Nautilo 桌面端打开「设置 → 远程连接」，选择「配对新设备」。在手机上扫描配对二维码，在电脑上核对数字并确认。连接期间电脑需保持在线。

The Android companion is built from the development branch. See the [build and pairing guide](https://github.com/zhufish-aa/Nautilo/blob/feat/unified-workspace-polish-20261103/apps/mobile/README.md) for setup.
